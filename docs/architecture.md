# HomeOps-AI Architecture

## Raspberry Pi

The Raspberry Pi will act as the primary always-on HomeOps-AI node.

Planned responsibilities:

- Network monitoring
- Device discovery
- Python automation
- Ansible controller
- Data storage
- Security log collection
- API/backend services

## Main Computer

The main computer will provide virtualization resources for:

- Kali Linux
- Ubuntu Server
- Windows
- Security testing environments

## Future Infrastructure

Possible future additions:

- Managed Ethernet switch
- VLAN segmentation
- OPNsense firewall
- Dedicated virtualization server
